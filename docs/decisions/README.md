# Registro de decisiones (ADR)

Cada decisión técnica importante se registra aquí: qué se decidió, por qué y qué alternativas se descartaron. Así cualquier persona o agente entiende el porqué sin rehacer la discusión.

- Un archivo por decisión: `NNNN-titulo-corto.md` (numeración correlativa).
- No se editan decisiones antiguas: si cambia algo, se crea un ADR nuevo que **reemplaza** al anterior y se marca el viejo como `Reemplazada por NNNN`.
- Plantilla: [`0000-template.md`](0000-template.md).
